# Intu.eat — рабочая тетрадь интуитивного питания

Веб-приложение для самостоятельной работы по методу интуитивного питания —
подход, вдохновлённый принципами Элиз Реш и Эвелин Триболе и их адаптацией
Светланой Бронниковой для русскоязычной аудитории.

## Возможности

- **Дневник питания** — фиксация голода и сытости по шкале 0–10, эмоций
  до/после еды, повода поесть, мыслей и уровня удовлетворения. Без подсчёта
  калорий, БЖУ или веса тела — дневник наблюдения, а не контроля.
- **Курс упражнений по неделям** — 10 недель с текстами, упражнениями на
  рефлексию, практиками и чек-листами по ключевым темам интуитивного питания
  (диетическое мышление, голод и сытость, внутренний критик, эмоциональный
  голод, образ тела, движение, бережная забота о здоровье).
- **Еженедельный отчёт** — автоматический анализ паттернов питания за
  выбранную неделю на основе записей дневника: тренды голода/сытости,
  эмоциональные триггеры, доля диетических мыслей, удовлетворение от еды и
  персональные рекомендации.

Все данные хранятся локально в браузере (localStorage), без сервера и
регистрации.

⚠️ Приложение — инструмент для самостоятельной работы и не заменяет
консультацию специалиста по РПП.

## Стек

React + TypeScript + Vite + Tailwind CSS v4, react-router-dom, zustand,
date-fns.

## Разработка

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # production-сборка (tsc -b && vite build)
```
